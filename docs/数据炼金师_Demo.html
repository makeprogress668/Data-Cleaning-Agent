How it works

AI 理解 + 确定性执行

它不是让大模型直接改你的数据，而是让 AI 做理解和规划，让工程化引擎做可验证的执行。

Layer 1 · Agent 理解层

负责"想清楚要做什么"

  • 理解用户的自然语言业务目标
  • 定位上传文件中的表、字段和关系
  • 生成可审阅的 JobConfig 处理计划
  • 解释结果、风险和下一步动作
➜
Layer 2 · 确定性执行层

负责"稳稳地把它做对"

  • 读取多格式文件并做数据画像
  • 执行 lookup、公式、清洗和规则校验
  • 生成异常复核、质量评分和图表
  • 保留审计追溯，绝不黑盒改数
✅ 计划由 AI 起草，但每一步都经过白名单 + Schema + 字段引用校验；LLM 不可用时自动回退到确定性引擎，流程不中断。这保证了 Agent 的灵活，又不牺牲数据处理的确定性。
